# Рыночная площадь деревни

Стимпанк-средневековый рынок в зоне стройплощадки «Рыночная площадь» (сцена редактора, `buildSites`).
Ориентир — города Lineage 2 и референс автора (кольцевая площадь, фонтан, ряды лавок, фахверк, зелень по краю);
всё своё, процедурное, без чужих моделей и текстур. Рынок «поставлен руками»: дороги кривые и разной ширины,
лавки сдвинуты и развёрнуты по-своему, вокруг — кучи товара, заборы, деревья.

## Состав

| Модель | Что это |
|---|---|
| `mkt_stall_<класс>` ×21 | лавка каждого класса из `shared/class-system.js`: латунная вывеска-шестерня с гербом класса, герб и на кронштейне, цвет полога, товар на прилавке и полках |
| `mkt_stall_food`, `mkt_stall_supplies` | общие лавки: снедь, расходники |
| `mkt_fountain` | фонтан Основателя: бронзовый механик, восьмигранная чаша, клумбы, медные изливы, манометры |
| `mkt_pavilion` | зелёный торговый шатёр: прилавок с тканями, самовар-котёл с трубой |
| `mkt_house_red/blue/green` | фахверковые дома с черепицей, латунной шестернёй на фасаде и медным баком на крыше |
| `mkt_steam_boiler` | паровой котёл: клёпаная медь, огонь в топке, манометры, вентили, дымовая труба |
| `mkt_steam_wagon` | паровой тягач: котёл на раме, ведущие колёса, маховик, будка |
| `mkt_pipe_span` | паропровод на козлах над улицей (вентиль, манометр); растягивается по X под ширину дороги |
| `mkt_lamp`, `mkt_banner`, `mkt_bunting` | паровой фонарь с баком и манометром, синий вымпел, гирлянда флажков (растягивается по X между вымпелами) |
| `mkt_table_produce`, `mkt_table_wares`, `mkt_fence`, `mkt_handcart` | столы с овощами и медной утварью, забор, ручная тележка |
| `mkt_crate`, `mkt_crates_stack`, `mkt_barrel`, `mkt_sacks`, `mkt_bench`, `mkt_kettle_cart` | мелочь рынка |

Из библиотеки проекта: дирижабль и причальная мачта (`airship`, `airship_mooring_mast`), деревья, кусты и цветы,
которыми автор озеленял деревню.

Все модели `mkt_*` — в библиотеке редактора, раздел «Модели Claude (Blender)» (`madeBy: 'claude'`), и в своих категориях.

## Земля и дороги — кисть террейна

Брусчатку, утоптанную землю и траву рисует `paint_market.py` (с разрешения автора, только внутри контура зоны):
слой 0 — брусчатка (кривое кольцо, выходы, площадка у фонтана; кромки мягкие и рваные, камень местами уходит в землю),
слои 2+3 — спокойная земля, слой 1 — редкие пятна травы за кольцом. Покраска полупрозрачная: площадь не выбивается
яркостью из террейна.
Дороги берутся из `market-roads.json`, который пишет раскладка; по ним же раскладка не ставит ничего на дорогу.
Карта покраски 1024² (≈3.6 м/пикс.), поэтому кромки естественно мягкие. Перед первой записью копии карт
кладутся в `data/terrain-backups/*.pre-market.png`.

## Оптимизация (мобильный браузер)

- один атлас `client/assets/props/textures/mkt_atlas.webp` (1024², WebP q82, 138 КБ) и один материал `mkt_atlas` на все модели рынка;
- GLB + Draco (настройки `convert-assets.js`), 1–35 КБ на модель, до 3 LOD (ярус пишется, если он легче на 30%+);
- instancing: каждая модель — один InstancedMesh, повторы (фонари, вымпелы, ящики, бочки, заборы, дома) — бесплатно;
- дороги — покраска террейна, а не геометрия; мелочь без теней.

## Пересборка

```
python scripts/market-square/atlas_market.py
"D:/3d/Blernder/blender.exe" -b --factory-startup -P scripts/market-square/build_market.py
node scripts/market-square/register_market.js
node scripts/market-square/layout_market.js --dry
python scripts/market-square/paint_market.py
node scripts/market-square/layout_market.js
```

- `build_market.py -- mkt_fountain mkt_lamp` — пересобрать только эти детали; `-- ... --preview out.png` — контактный лист.
- Общие построители мешей (MB, box, cylinder, decal…) берутся из `scripts/operators-territory/build_kit.py`, атлас подменяется.
- Раскладка детерминирована (свой генератор случайных чисел): повторный запуск ставит то же самое.
- `layout_market.js --dry --dump plan.json` — отчёт без записи сцены (дороги в `market-roads.json` пишет всегда).
- Центр и контур берутся из стройплощадки «Рыночная площадь».
- Раскладка заменяет только свои объекты (`mkt_*`). Из чужого она сняла 13 объектов прежнего рынка (список id в скрипте).
- `paint_market.py` в прямоугольнике рынка рисует поверх карты до рынка (бэкап), поэтому запуск можно повторять. Сила покраски неполная: сквозь неё проступает родной грунт террейна, а к краю зоны покраска рвано сходит на нет.
