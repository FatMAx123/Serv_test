# Руководство Администратора и Game Master (GM Guide)
## Lineage 2: Island of Singing Steel

Данный документ содержит полное руководство по управлению сервером, выдаче прав, командам Game Master (GM), визуальным эффектам и горячим клавишам отладки.

---

## 1. Как выдать права Администратора (GM)

В проекте предусмотрено 4 удобных способа назначения прав:

### Способ А: В один клик через `make-gm.bat` (Рекомендуется)
1. В папке проекта дважды кликните по файлу `make-gm.bat`.
2. Введите имя персонажа (например: `Hero`, `Operator-965b` или любое созданное имя).
3. Нажмите **Enter** — персонажу будет моментально присвоен статус Администратора (`AccessLevel: 100`).

### Способ Б: Прямо в консоли запущенного сервера
В окне сервера (`start-server.bat`) доступен интерактивный ввод команд. Введите команду:
```text
setgm <ИмяПерсонажа> 100
```
*(Права применяются немедленно, даже если персонаж прямо сейчас находится в игре).*

### Способ В: Через консольную утилиту `gm-tool.js`
В терминале редактора (Ctrl + `) выполните:
```bash
# Выдать права Администратора (100)
node server/gm-tool.js set "ИмяПерсонажа" 100

# Выдать права Модератора (50)
node server/gm-tool.js set "ИмяПерсонажа" 50

# Посмотреть список всех игроков и их статус
node server/gm-tool.js list

# Снять права GM
node server/gm-tool.js revoke "ИмяПерсонажа"
```

### Способ Г: Вручную в файле конфигурации
Откройте файл `data/gm-access.json` и добавьте имя персонажа в нижнем регистре:
```json
{
  "characters": {
    "hero": 100
  },
  "accounts": {}
}
```

## 2. Иерархия уровней доступа (Access Levels)

| Уровень | Роль | Возможности |
| :---: | :--- | :--- |
| **0** | **Обычный игрок** | Стандартный геймплей. Все `//` команды и F2 заблокированы (`access_denied`). |
| **50..99** | **Модератор** | Порядок и чат: `//announce`, `//kick`, `//mute`, `//unmute`, `//teleport`, `//goto`, `//recall`, `//info`. |
| **100** | **Главный Администратор** | Полный доступ: `//invul`, `//heal`, `//speed`, `//aura`, `//give`, `//spawn`, `//killmob`, `//ban`, `//unban`, `//setgm`, `//revokegm`, **F2** Редактор сцены. |

## 3. Визуальное выделение GM в игре

В Lineage 2 Game Master обладает уникальным внешним видом, выделяющим его среди обычных персонажей:

1. **Цвет никнейма**:
   - Яркий неоновый циан / лазурный цвет (`#00f0ff`) с неоновым ореолом свечения над головой.
2. **Титул над ником**:
   - Золотой титул `[Administrator]` (для уровня 100) или `[Game Master]` (для уровня 50+) со сиянием `#ffd700`.
3. **Свечение Чемпиона и Героя Lineage 2 (L2 Champion & Hero Glow)**:
   - **Динамическое освещение модели (PointLight)**: персонаж излучает яркий цветной свет, освещающий 3D-модель (доспехи, оружие, лицо) и землю вокруг него.
   - **Объёмный вертикальный ореол / столб маны (Body Energy Veil)**: двухслойный цилиндр струящейся маны, полностью окутывающий силуэт персонажа от ног до макушки.
   - **Двойной рунический магический круг**: плотно на поверхности земли под ногами с 12 рунами и кардинальными звёздами.
   - **Концентрические ударные волны маны (Shockwave Waves)**: периодически расширяющиеся по земле кольца энергии.
   - **Восходящие по спирали искры и языки пламени**: 14 светящихся частиц, вихрем поднимающихся вокруг корпуса.
   - **Сияние ядра тела**: мягкий аддитивный ореол в области торса.
   - Аура транслируется всем игрокам по сети в зоне видимости (AOI).

### Управление аурой в реальном времени:
Администратор может в любой момент переключить визуальный стиль прямо из игрового чата:
- `//aura blue` (или `//aura cyan`, `//aura gm`) — Классический сапфирово-бирюзовый **Blue Champion L2** (по умолчанию).
- `//aura hero` — Легендарное сияние **Героя Lineage 2** (бело-лазурный столб света).
- `//aura red` — Грозный огненно-багровый **Red Champion L2**.
- `//aura gold` — Величественный имперский **Golden Champion L2**.
- `//aura off` — Скрыть ауру (режим скрытного наблюдения).

## 4. Справочник игровых команд GM (вводятся в чат)

Все команды вводятся в чате игры через двойной слэш (`//`):

### Основные команды и персонаж
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `//help` | Показать список доступных команд в соответствии с вашим рангом. | `//help` |
| `//invul` | Включить / выключить режим абсолютной неуязвимости (бессмертие). | `//invul` |
| `//heal [цель]` | Полное восстановление HP и MP себе или выбранному игроку. | `//heal` или `//heal Operator` |
| `//speed <множитель>` | Изменить скорость бега (от 1.0x до 10.0x) со снятием античит-ограничений. | `//speed 3` |
| `//aura <тип>` | Сменить стиль ауры Чемпиона (`blue`, `red`, `gold`, `off`). | `//aura red` |

### Перемещение и телепортация
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `//teleport <x> <z>` | Мгновенное перемещение в указанные координаты мира. | `//teleport -150 -250` |
| `//goto <игрок>` | Телепортироваться к указанному игроку. | `//goto Hero` |
| `//recall <игрок>` | Призвать игрока к себе. | `//recall Hero` |

### Модерация и порядок
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `//announce <текст>` | Разослать глобальное системное оповещение всем игрокам. | `//announce Сервер будет перезагружен через 10 минут!` |
| `//kick <игрок>` | Принудительно отключить игрока от сервера (код 4011). | `//kick Troublemaker` |
| `//mute <имя> <мин> [причина]` | Заблокировать игроку отправку сообщений в чат. | `//mute Troublemaker 60 Спам` |
| `//unmute <имя>` | Снять блокировку чата. | `//unmute Troublemaker` |
| `//ban <имя> [мин] [причина]` | Заблокировать доступ игроку (по умолчанию 1440 мин / 24 ч). | `//ban BadActor 1440 Чит` |
| `//unban <имя>` | Разблокировать доступ игроку. | `//unban BadActor` |
| `//info <игрок>` | Просмотреть информацию об игроке (HP, уровень, координаты, IP/YID). | `//info Hero` |

### Экономика и создание объектов
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `//give <имя> <itemId> [кол-во] [плюс]` | Выдать любой предмет из каталога (оружие, броню, ресурсы, адену). | `//give Hero synthetic_oil 50` |
| `//spawn <mobId> [кол-во]` | Призвать одного или группу монстров рядом с собой (до 10 шт). | `//spawn swamp_screamer 3` |
| `//killmob` | Мгновенно уничтожить ближайшего живого монстра в радиусе 15 метров. | `//killmob` |
| `//setgm <имя> [уровень]` | Назначить игроку статус GM прямо из игры. | `//setgm Friend 100` |
| `//revokegm <имя>` | Снять статус GM с игрока прямо из игры. | `//revokegm ExMod` |

## 5. Горячие клавиши и Редактор сцены

Для администраторов в клиенте игры активны специальные функции:

- **`F2` — 3D Редактор мира (Scene Editor)**:
  - Открывает полноценный встроенный редактор локации острова.
  - Позволяет выбирать, перемещать, поворачивать и масштабировать любые здания, кусты, деревья, точки спавна мобов и NPC.
  - Сохранение внесенных изменений прямо на сервер.
- **`F3` — Переключение расширенного FPS / Performance HUD**:
  - Отображает текущий FPS, время кадра CPU, время просчета видимости толпы (Crowd MS), задержку рендера Three.js и число Draw Calls.
  - Плашку HUD можно перетаскивать мышью или пальцем по экрану.
- **`F4` — Инспектор видимости Lineage 2 (Visibility & Culling Inspector)**:
  - Включает отображение колец дистанций видимости (`ActorsMax`, `Foliage`, `Nameplate`).
  - Показывает статистику Frustum Culling и Distance Culling в реальном времени.

## 6. Журнал аудита (Audit Logging)

Все действия администраторов и модераторов автоматически протоколируются сервером.
Журнал ведется в файле:
```text
data/gm-audit.log
```
Каждая запись содержит точное время (ISO), имя администратора, команду, параметры и IP/аккаунт цели.
