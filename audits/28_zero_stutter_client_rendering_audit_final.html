1. Постановка Проблемы

В WebGL-клиенте на базе Three.js наблюдался критический микрофриз (100–300+ мс) при входе любого стороннего игрока в поле зрения камеры. В условиях многопользовательской MMO (в городах, на клановых сборах или при внезапных PvP-нападениях) это приводило к срыву управления и потере контроля над персонажем.

Цель аудита: Ликвидировать любые синхронные остановки основного потока JS и WebGL-контекста, обеспечив монолитный фреймрейт 60 FPS при динамическом появлении любого числа персонажей.

2. Пять Узких Мест Рендер-Конвейера

№ Узкое Место Механика Дефекта Влияние на Производительность
1 Инвалидация кэша шейдеров освещением warmupPipeline запускался до создания ночных ламп DayNight (было 1 солнце, стало 3 источника). Three.js генерировал директиву #define NUM_DIR_LIGHTS 3 и сбрасывал весь кэш как невалидный. Синхронная компиляция GLSL (120–250 мс)
2 Различие ключей теней (receiveShadow) Локальный игрок рендерится с receiveShadow = true, а клоны сетевых игроков — с receiveShadow = false. Шейдер без теней ранее не прогревался. Повторная компиляция шейдера клона
3 Холодный stall буферов VBO/VAO для LOD 1 / 2 Игроки появляются на дистанции > 15м, мгновенно включая меши LOD 1. Буферы вершин не были аллоцированы в GPU VRAM, вызывая блокировку шины PCI-e. Аппаратный GPU-stall (30–60 мс)
4 CPU цикл чтения пикселей и mat.needsUpdate В tintHairMaterial производилось синхронное обесцвечивание текстуры 1024x1024 через getImageData и выставлялся needsUpdate = true вместо смены юниформов. Зависание JS Event Loop (20–40 мс)
5 Генерация мипмапов неймплейта и дубль сетапа оружия Плашка имени не отключала generateMipmaps, а в net-ws.js происходил избыточный вызов setWeapon(..., { force: true }). Лишние GPU-проходы и аллокации

3. Архитектурные Решения и Внедрение

Комплекс решений перестроил жизненный цикл инициализации клиентского движка по принципу Zero Runtime Allocation & Pre-Warmed GPU Shaders:

// client/js/main.js — Синхронизация порядка инициализации // 1. Асинхронный фоновый предзаказ ассетов CharModel.preloadAssets(); // 2. Инициализация освещения сцены, дня/ночи и теней this.dayNight = new DayNight(this.scene, this.renderer); this.setShadowQuality(this.config.shadowQuality); // 3. Полный глубокий прогрев пайплайна с ФИНАЛЬНЫМ светом (#define NUM_DIR_LIGHTS) CharModel.warmupPipeline(this.renderer, this.camera, this.scene);
// client/js/char-model.js — Scratch Render Pass в оффскрин буфер const scratchTarget = new THREE.WebGLRenderTarget(1, 1); const origTarget = renderer.getRenderTarget(); renderer.setRenderTarget(scratchTarget); scratchMesh.position.set(0, -9900, 0); // Вне поля зрения камеры // Принудительный рендер форсирует аллокацию VBO / VAO в видеопамяти renderer.render(scratchScene, scratchCam); renderer.setRenderTarget(origTarget); scratchTarget.dispose();
