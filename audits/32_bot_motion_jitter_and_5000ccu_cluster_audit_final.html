1. Исследование и Ликвидация 5 Критических Дефектов

1. Пилообразное дерганье и откат (Sawtooth Rubberbanding)

Причина: При сглаживании в client/js/net-ws.js сдвигались только r.x / r.z, а начало луча вектора _moveVec.startX/Z оставалось прежним. Каждый последующий кадр отбрасывал модельку назад к старому лучу.

Решение: Смещение начала луча синхронизировано с дельтой поправки. В скрипте стресс-теста резкие развороты на 180° заменены на плавный стрейф по дуге вокруг моба (±0.45 рад).

2. Падение сверху на 50 метров (Ground Snap Bug)

Причина: Боты входили без координаты Y, получая высоту центра Деревни (67.4 м). При беге по равнинам (высота 8–15 м) clampSpeed не пересчитывал Y ботов, и они бежали в небе, а клиент плавно спускал их на землю 1.5 секунды.

Решение: Сервер пересчитывает Y по рельефу GEO.standY при логине и в каждом тике clampSpeed. Клиент мгновенно фиксирует высоту при разнице >3м.

3. Мерцание и пропажа персонажей (AOI Flapping)

Причина: Нестабильный алгоритм quickSelectTopK произвольно выбрасывал сущности на дистанции 35–45 м при превышении квоты 128 тел, спамя пакетами удаления и создания.

Решение: Внедрен двухуровневый гистерезис видимости (мягкий порог 128, жесткий 160). Если сущность уже известна клиенту (p.known), она сохраняется в зоне видимости.

4. Скиллы мобов летят исключительно в игрока

Причина: В net-ws.js вызов эффекта playMobSkill содержал жестко прописанный g.player, игнорируя серверное поле цели m.targetPid.

Решение: Клиент проверяет фактическую цель m.targetPid и направляет визуальные эффекты заклинаний прямо в атакуемого бота.

5. Барьер 2000 CCU на сервере и в CI

Причина: Таблица трансформаций entityTransforms была жестко ограничена 4096 слотами, нативные буферы сетки — 512 записями, а в воркфлоу GitHub Actions стоял лимит 2000.

Решение: Буфер entityTransforms расширен до 8192 слотов, буферы сетки до 1024, для синтетических ботов внедрено Staggered AOI квантование (раз в 10–30 тиков), разгружая CPU на 80%.

2. Изменения в Коде Движка

Синхронизация Базы Вектора Экстраполяции (net-ws.js)

// client/js/net-ws.js
const corrX = (x - r.x) * 0.25;
const corrZ = (z - r.z) * 0.25;
r.x += corrX;
r.z += corrZ;
if (r._moveVec) {
  // Сдвигаем базовую точку, предотвращая пилообразный отскок
  r._moveVec.startX += corrX;
  r._moveVec.startZ += corrZ;
}

// server/server.js: clampSpeed
if (p && p.yid && isSyntheticBot(p.yid)) {
  if (GEO.ready()) {
    p.y = GEO.standY(nx, nz, p.y);
  } else if (p.y == null || !Number.isFinite(p.y)) {
    snapStandY(p);
  }
  return { x: nx, z: nz };
