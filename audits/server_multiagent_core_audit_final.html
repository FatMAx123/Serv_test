A1 Agent 1: Network & Protocol Architect
1 Critical, 1 Medium
BUG-NET-01: Циклическое переполнение 16-битного seq в OP_MOVE CRITICAL
shared/net-pack-binary.js (L201), server/server.js (L4695-4698)
В бинарном кодеке движка для экономии трафика номер пакета движения упаковывается в 16-битное число: buf.writeUInt16LE(s, 1). Когда игрок непрерывно бегает, он отправляет до 20 пакетов движения в секунду. Через ~1 час активного бега seq достигает 65535, а следующий пакет отправляет 0 или 1. Сервер проверяет if (msg.seq <= p.seq) return;. Так как 1 <= 65535, все последующие пакеты перемещения навечно блокируются сервером. 
// Решение проблемы переполнения в server/server.js:
if (msg.seq != null) {
  if (!Number.isSafeInteger(msg.seq) || msg.seq <= 0) return;
  const isWrap = (p.seq > 60000 && msg.seq < 5000);
  if (!isWrap && msg.seq <= p.seq) return;
  p.seq = msg.seq;
}
A2 Agent 2: World State & Simulation Engineer
1 Critical, 1 High
BUG-SRV-01: Дефект передачи строковых ключей в aoi.enter при Handoff CRITICAL
server/server.js (L4365-4369), client/js/net-ws.js (L1324)
В функции adoptClusterHandoff при переходе игрока в зону другого рабочего процесса вызывается send(p, { t: 'aoi', enter: aoi.enter, leave: aoi.leave });. Однако aoi.enter содержит массив строковых ключей ['p102', 'm5'], а не полные объекты снапшотов. Клиент ожидает поля s.x, s.z, s.hp, s.name, что приводит к ошибкам десериализации и исчезновению сущностей на границе зон.
PERF-GRID-01: Отсутствие эвикции неиспользуемых ячеек в SpatialGrid HIGH
server/spatial-grid.js (L41-58)
В сетке SpatialGrid метод clear() очищает только сущности в активных ячейках. Сами объекты ячеек навсегда сохраняются в this.cells = new Map(), вызывая неограниченное разрастание памяти при долгой работе сервера.
