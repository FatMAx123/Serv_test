## 2. Многофакторная Формула Шанса Прохождения Дебаффов (L2 Canon)

В каноне Lineage 2 C1/C4 шанс наложения магических и физических отрицательных эффектов определяется формулой:

$$P_{\text{land}} = \text{BaseChance} \times \left(\frac{\text{AtkStatMod}}{\text{DefStatMod}}\right) \times \text{LvlFactor} \times \sqrt{\frac{\text{C.Atk} \times \text{ShotMod}}{\text{C.Def}}} \times (1 - \text{ResistMod})$$

### Ключевые множители:
1. **Базовый шанс ($\text{BaseChance}$):**
   - Ice Bolt (`eng_pressure_seal`, `con_coolant_bolt`): **80%** (0.80).
   - Curse: Weakness (`eng_curse_weak`): **70%** (0.70).
   - Curse: Poison (`eng_curse_corrode`): **70%** (0.70).
   - Stun Attack / Shield Bash: **70%** (0.70).
2. **Модификатор характеристик ($\frac{\text{AtkStatMod}}{\text{DefStatMod}}$):**
   - **Магические/контурные дебаффы:** зависит от $\text{INT}$ атакующего и $\text{MEN}$ защитника.
     $$\text{StatMod} = \frac{1 + (\text{INT} - 20) \times 0.015}{1 + (\text{MEN} - 20) \times 0.015}$$
   - **Физические оглушения (Stun):** зависит от $\text{STR}$ атакующего и $\text{CON}$ защитника.
     $$\text{StatMod} = \frac{1 + (\text{STR} - 20) \times 0.015}{1 + (\text{CON} - 20) \times 0.02}$$
3. **Множитель разницы уровней ($\text{LvlFactor}$):**
   - Если цель выше уровнем, шанс снижается на 3.5% за каждый уровень разницы:
     $$\text{LvlFactor} = 1 - \max(0, \text{TargetLvl} - \text{AttackerLvl}) \times 0.035$$
   - Защита от халявного кайта высокоуровневых мобов и боссов низкоуровневыми магами.
4. **Отношение магической атаки к защите ($\sqrt{\frac{\text{C.Atk} \times \text{ShotMod}}{\text{C.Def}}}$):**
   - Заряды контура (Spiritshots / Blessed Spiritshots) дают множитель урона/мощности `2.0x` / `4.0x`, что увеличивает силу прохождения дебаффа в $\sqrt{2} \approx 1.41$ или $\sqrt{4} = 2.0$ раза.
   - Защита цели (C.Def / M.Def) снижает шанс прохождения.
5. **Сопротивления и статус рейд-босса ($\text{ResistMod}$):**
   - Рейд-боссы имеют базовое сопротивление дебаффам **60%** (`resistMod = 0.60`).
   - Рейд-боссы обладают **100% иммунитетом к оглушению** (`isStun` на РБ $\rightarrow$ шанс 0%).
6. **Канонические границы (Clamp):**
   - Шанс жестко ограничен коридором: **минимум 5%** (шанс на чудо), **максимум 95%** (5% шанс на срыв/сопротивление).

## 3. Выполненные Архитектурные Изменения в Коде

### 3.1. `shared/l2-combat.js`
Функции `magicLandChance` и `rollMagicLand` расширены для поддержки полного набора параметров:
```javascript
function magicLandChance(attackerLvl, targetLvl, baseChance, options) {
  options = options || {};
  let chance = baseChance != null ? baseChance : 0.8;
  const aLvl = Math.max(1, attackerLvl | 0);
  const tLvl = Math.max(1, targetLvl | 0);

  // 1. Уровневый штраф
  if (tLvl > aLvl) {
    chance *= Math.max(0.1, 1 - (tLvl - aLvl) * 0.035);
  } else {
    chance *= Math.min(1.2, 1 + (aLvl - tLvl) * 0.015);
  }

  // 2. Влияние характеристик (INT vs MEN для магии, STR vs CON для стана)
  if (options.isStun) {
    const atkStr = options.atkStr || 20;
    const defCon = options.defCon || 20;
    chance *= (1 + (atkStr - 20) * 0.015) / (1 + (defCon - 20) * 0.02);
  } else {
    const atkInt = options.atkInt || 20;
    const defMen = options.defMen || 20;
    chance *= (1 + (atkInt - 20) * 0.015) / (1 + (defMen - 20) * 0.015);
  }

  // 3. Отношение атаки к защите + заряды соулшотов/спиритшотов
  if (options.cAtk && options.cDef) {
    const shotMult = options.shotMod || 1.0;
    const pwrRatio = Math.sqrt((options.cAtk * shotMult) / Math.max(1, options.cDef));
    chance *= Math.max(0.5, Math.min(1.5, pwrRatio));
  }

  // 4. Рейд-боссы и сопротивления
  if (options.isRaid) {
    if (options.isStun) return 0; // Полный иммунитет РБ к стану
    chance *= 0.40; // 60% резист дебаффам
  }
  if (options.resistMod) chance *= (1 - options.resistMod);

  return Math.max(0.05, Math.min(0.95, chance));
}
```

### 3.2. `shared/skill-db.js` и `client/js/skills.js`
Синхронизированы спецификации `con_coolant_bolt` с каноническим эталоном:
- `duration: 60` секунд (вместо 5).
- `slowPercent: 0.20` (-20% скорости перемещения).
- `cooldown: 2` секунды (вместо 4).
- `chargeTime: 3.1` секунды (канонический каст Ice Bolt).
- `effectPerLevel: { skillPower: 0.12 }`.

### 3.3. `server/handlers/mob-handler.js`
В основном цикле тика мобов (`tickMobAi`) добавлена строгая проверка оглушения:
```javascript
if (m.stunUntil && m.stunUntil > now) return;
```
Пока моб находится в оглушении (`m.stunUntil > now`), он полностью обездвижен, не выбирает цели и не может совершать автоатаки или применять способности.

### 3.4. `server/server.js` (PvE и PvP интеграция)
1. **Списание зарядов на дебаффы без прямого урона:**
   Ранее заряды списывались только при `hasDmg`. Теперь проверка изменена на `if (hasDmg || hasDebuffFx)`, благодаря чему спиритшоты и соулшоты усиливают прохождение дебаффов, даже если умение не наносит прямого урона (`eng_curse_weak`, `mech_emergency_shutdown`).
2. **Расчет прохождения по мобам:**
   При вызове `L2.rollMagicLand` в PvE передаются параметры атакующего игрока и моба:
   `cAtk`, `cDef`, `skillShotMod`, `isRaid`, `isStun`, `atkStr`, `defCon`, `stunResist`.
3. **Наложение оглушения на мобов:**
   При прохождении стана устанавливается `m.stunUntil = now + sDurMs`, отправляется `applyMobEffect(m, { kind: 'stun', ... })` и формируется результат `kind: 'stun'` для рассылки в AOI.
4. **Полноценная обработка дебаффов в PvP (`attack_player`):**
   Ранее в PvP обрабатывался только физический урон. Теперь для умений с дебаффами рассчитывается `rollMagicLand` против боевых стат цели (`tgt.combatPack`), после чего применяются:
   - Замедление (`slow`).
   - Снижение атаки (`weakness`).
   - DoT-урон (`dot`).
   - Снижение защиты (`pdef`).
   - Оглушение (`stun`).
   Синхронизируются пакеты `status_fx`, `pushEffects(tgt)` и `pushCombatStats(tgt)`.
