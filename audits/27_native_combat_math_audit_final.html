⚙️ 1. Архитектурная Цель

В MMO-сервере с динамическим боем (10 тиков/сек / 100 мс) автоатаки сотен игроков и мобов, касты умений, прожатие зарядов душ (Soulshots / Spiritshots) и блоки щитом создают колоссальное число мелких вычислений. Перенос тяжелых боевых расчетов в нативный C++ аддон позволяет:

  • Избежать микроаллокаций промежуточных объектов в Eden-куче V8 (Zero-GC).
  • Использовать аппаратные инструкции корня, степени и автовекторизацию компилятора GCC/MSVC.
  • Пакетно рассчитывать сотни столкновений за один вызов C++ функции через общий буфер Float32Array ➔ Int32Array.

📐 2. Канонические Формулы Боя Lineage 2 C1

1. Точность и Уклонение:
HitChance = clamp(75 + (Accuracy - Evasion) * 5, 5, 98)
Базовый шанс при равных статах: 75%
2. Блок Щитом:
BlockChance = clamp(20 + (ShieldDef / (P.Def + ShieldDef)) * 30 + Bonus, 0, 70)
При блоке урон снижается на ShieldDef (P.Def_eff = P.Def + ShieldDef)
3. Физический Урон (P.Atk):
D = floor(70 * (P.Atk * SS + Power * SS) / P.Def * Rand(0.85 .. 1.15) * CritMod)
Soulshot = x2.0, Физ. Крит = x2.0
4. Контурный / Магический Урон:
D = floor(91 * Power * (sqrt(C.Atk) / C.Def) * SPS * Rand(0.90 .. 1.10) * CritMod)
Spiritshot = x1.5 / Blessed = x2.0, Маг. Крит = x3.0
