VULN-PROD2-01 Захват чужих имен персонажей и эскалация GM-привилегий
CRITICAL 9.1
CWE Категория
CWE-287, CWE-285, CWE-269
Затронутые файлы
server/player-db.js, server/server.js, server/http/admin-api.js
Риск эксплуатации
Неавторизованный захват административных прав (//give, //ban, //setgm) через создание персонажа с именем GM.

Суть дефекта: При регистрации персонажа в doLoginInner и /api/chars/create проверялись имена только в рамках одного аккаунта. В recordFromProfile при совпадении имени с записью GM новому персонажу без сверки yid присваивался accessLevel = 100.

// player-db.js: Безопасная проверка и изоляция прав isNameTaken(name, excludeYid) { if (!name) return false; const rec = characters.get(normalizeKey(name)); if (!rec) return false; if (excludeYid && String(rec.yid) === String(excludeYid)) return false; return true; } // Запрет наследования прав GM чужим аккаунтом else if (currentRecord && String(currentRecord.yid) === String(yid) && currentRecord.accessLevel >= 50) { accessLevel = currentRecord.accessLevel; }
VULN-PROD2-02 Целочисленное переполнение (32-bit signed int overflow) в торговле и инвентаре
HIGH 7.5
CWE Категория
CWE-190 (Integer Overflow or Wraparound)
Затронутые файлы
trade-handler.js, store-handler.js, item-plus-utils.js, death-rules.js, server.js
Риск эксплуатации
Открытие лавок покупки на миллиарды валюты без денег (отрицательный totalNeeded), срыв обменов.

Суть дефекта: Использование побитового | 0 превращало числа больше 2.147 млрд в отрицательные, обходя проверки баланса currencyOf(p) < totalNeeded.

// Безопасный расчет totalNeeded без переполнения в 32-bit int const count = Math.max(0, Math.floor(Number(it.count))) || 0; const price = Math.max(0, Math.floor(Number(it.price))) || 0; totalNeeded = Math.min(Number.MAX_SAFE_INTEGER, totalNeeded + (count * price));
VULN-PROD2-03 Отсутствие проверки авторизации в POST-ручках static-http.js
HIGH 7.4
CWE Категория
CWE-306, CWE-284
Затронутые файлы
server/static-http.js
Риск эксплуатации
Неавторизованная заливка ассетов и перезапись серверного кода сцены через POST-запросы без Origin.

Суть дефекта: Условие if (origin && !localOrigin) пропускало запросы без заголовка Origin, а флаг EDITOR_ENABLED по умолчанию был активен.

const EDITOR_ENABLED = process.env.NODE_ENV !== 'production' && ((process.env.EDITOR_ENABLED || '0') === '1'); if (req.method === 'POST') { if (!EDITOR_ENABLED || !editorAuthorized(req)) return editorDisabled(res); if (origin && !localOrigin) { res.writeHead(403, JSON_HEAD); return res.end(JSON.stringify({ ok: false, error: 'origin not allowed' })); } }

MEDIUM 5.3
CWE Категория
CWE-400, CWE-770
Затронутые файлы

Риск эксплуатации
Раздувание инвентаря выше 80 слотов, сбои обмена вещами и торговых диалогов.

const fit = NPCS.canFit(p.inv, L.itemId, L.count); if (!fit.ok) { send(p, { t: 'loot_fail', lid, reason: 'inv_full', need: fit.need, free: fit.free }); return; }
