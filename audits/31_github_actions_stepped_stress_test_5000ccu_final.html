🔧 Решение 4 Критических Проблем Заказчика
1. Дёрганье и отскоки ботов
Сервер блокировал Dead Reckoning для ботов (!isSyntheticBot), а клиент делал жесткий телепорт при запоздании пакета.
Решение: Снята блокировка _moveVec в server.js; в net-ws.js добавлен адаптивный lerp (шаг 0.25) при экстраполяции.
2. Боты не били мобов на спотах
Условие item.level > 5 ошибочно помечало всех мобов острова боссами, а боевой цикл ботов запрещал бить боссов.
Решение: Удалено условие в stress-test-3000.js. Боты бьют автоатакой и скиллами. Выбито >655 тыс. адены.
3. Скиллы мобов летели только в игрока
Поскольку боты не дамажили мобов, в таблице ненависти m.hate был только человек. topHatePlayer(m) всегда выбирал игрока.
Решение: Урон ботов заполняет m.hate. Мобы агрятся на ботов и кастуют скиллы в них. Включен ensureNearbyMobs(p).
4. Фиксация онлайна на 2048 CCU
Один раннер GitHub Actions упирается в лимит 2048 SNAT портов Azure Virtual Network Gateway на одно публичное назначение.
Решение: Спроектирована Matrix Strategy (3 параллельных раннера по 1700 CCU с разных IP для достижения 5000+ CCU).
