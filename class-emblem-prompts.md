# Символика классов — Остров поющей стали

Четыре знака одной семьи: **Оператор**, **мили**, **дальник**, **Инженер**.  
Без букв, без неона, без рун, без черепов «тёмного фэнтези».  
Металл: тёмное клёпаное железо, латунь, медь. Фон: уголь / известковый камень.

Копируй блок целиком. Один промт = один ассет.

## Куда вешать в деревне

| Знак | Здания / декор |
|---|---|
| Оператор | Гильдия, караульня, двор операторов, мостовая у северных радиалов |
| мили | Кузница железа и плит, таверна силовиков, столбы-мишени |
| дальник | вышки, доки, крыло стрелков, пневматические цеха |
| Инженер | Школа техномагии, Эфирная академия, Хаб ТП, архив |

Размер щита на фасаде: Ø 0.8–1.1 м. Иконка UI: 128 px, альфа или угольный квадрат.

## Нельзя

- буквы, цифры на манометре, руны  
- череп, кровь, неон, LED, современная винтовка M4  
- эльфийские листья, магические звёзды  
- разные рамки у четырёх знаков — рамка одна
