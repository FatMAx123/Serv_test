🚀 Инструкция: Как применить промпты в Tripo 3D

Шаг 1. Импорт меша

Загрузите в Tripo 3D готовую 3D-модель девушки-инженера woman_ing.fbx (или woman.blend). Выберите автоматический риггинг Humanoid Biped.

Шаг 2. Выбор типа анимации

В панели генерации движений выберите режим Text-to-Animation. Обязательно активируйте чекбокс In-Place Motion (анимация на месте без сдвига корневой кости).

Шаг 3. Вставка промпта

Нажмите кнопку «Копировать промпт» на любой карточке выше и вставьте английский текст в поле генерации Tripo. Запустите расчёт (обычно занимает 15–30 секунд).

Шаг 4. Экспорт в Project Steam

Экспортируйте результат как FBX / GLB с привязкой к скелету. Затем запустите node scripts/convert-assets.js для сжатия в Draco GLB для Three.js.
