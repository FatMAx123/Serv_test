Девушка-Инженер: 3D Модель, Анимации и Смена Экипировки

Официальное техническое руководство по архитектуре 3D-модели девушки-инженера. Полное объединение модульного меша (6 частей), библиотеки из 11 социальных эмоций и анимаций отдыха (сидение/вставание), системы сокетов оружия и щитов, а также технологии мгновенной смены брони в рантайме без перезагрузки анимаций.

🛡️ Бесшовная геометрия талии (Anti-Tear Waist Skinning):
Устранена проблема "дыр на спине" при наклонах вперед в анимациях sit_down (садится) и stand_up (встает):
  • Очистка весов ног на поясе: Mixamo ошибочно назначал до 70% веса бедер (Left/RightUpLeg) на верхний пояс шорт. При сгибании ног пояс утягивался вниз и разрывал модель. Веса ног на поясе обнулены.
  • Синхронный скининг талии: Верхний кант шорт и нижний край футболки получили идентичные пропорции костей mixamorig:Hips (50%) и mixamorig:Spine (50%), двигаясь строго синхронно.
  • Внутренний нахлёст (Tuck-In Collar +2.0 см): Верхний край пояса экструдирован внутрь футболки на 20 мм, создавая геометрический барьер — просветы исключены при любых углах наклона.
Единый Скелет
🦴 Скелетная основа (Armature)
Все анимации и части экипировки опираются на единый скелет из 65 костей Mixamo.
  • Единая иерархия: Корневая кость mixamorig:Hips находится на естественной высоте y = 0.564м, стопы касаются пола y = 0.0м.
  • Масштаб 1.0 (Метры): Устранены артефакты сантиметровых FBX (координаты 106 см). Теперь Three.js не искажает кости.
  • Универсальность: Любая новая анимация или броня, привязанная к этим 65 костям, работает мгновенно "из коробки".
Модульность
👗 Смена брони (Modular SkinnedMesh)
Как менять сеты брони (Кармиан, Зубей, Драконик), сохраняя непрерывность текущей анимации:
  • Анатомическое разделение: Персонаж разбит на 5 частей брони: tors (верх), Shorts (низ), hands (перчатки), legs (сапоги), Head (голова).
  • Принцип привязки (Binding): В Three.js при надевании новой брони не пересоздается персонаж. Вы просто подменяете геометрию узла: newMesh.bind(characterSkeleton).
  • Нулевой сброс анимаций: Персонаж продолжает бежать, сидеть или танцевать без лагов и задержек.
Сокеты Рук & Спины
⚔️ Точки крепления оружия (Sockets)
Оружие и щиты — это жесткие пропсы без собственного скелета персонажа, которые крепятся к костям:
  • Правая рука (Оружие): Сокет weaponHolder добавляется как дочерний объект к кости mixamorig:RightHand. В него загружаются мечи, посохи, дубины.
  • Левая рука (Щит / Парное): Сокет shieldHolder прикреплен к кости mixamorig:LeftForeArm или LeftHand.
  • За спиной (Ножны / Отдых): Сокет на кости mixamorig:Spine2 — для ношения посоха или двуручного оружия вне боя.
Кастомизация
💇 Кастом причесок & Окрашивание
Система кастомизации внешности Lineage 2 Style:
  • Быстрое перекрашивание: Текстура волос хранится в оттенках серого. Смена цвета волос делается через material.color.setHex() без рекомпиляции шейдеров.
  • Смена стрижки: Меш волос Haier выделен отдельно (файл hair.glb 41 КБ). Чтобы сменить стрижку, достаточно подменить узел прически на голове.
  • Кэш атласов: Текстуры упакованы в WebP 2048x2048, что экономит до 85% видеопамяти VRAM на мобильных устройствах.

1. СОКЕТЫ ОРУЖИЯ И ЩИТА (THREE.JS ATTACHMENT) 
// 1. Поиск кости правой кисти в модели
let rightHandBone = null;
let leftForeArmBone = null;

characterModel.traverse((node) => {
  if (node.isBone) {
    if (node.name === 'mixamorig:RightHand') rightHandBone = node;
    if (node.name === 'mixamorig:LeftForeArm') leftForeArmBone = node;
  }
});

// 2. Создание сокетов
const weaponSocket = new THREE.Group();
weaponSocket.name = 'socket_right_hand';
if (rightHandBone) rightHandBone.add(weaponSocket);

const shieldSocket = new THREE.Group();
shieldSocket.name = 'socket_left_arm';
if (leftForeArmBone) leftForeArmBone.add(shieldSocket);

// 3. Экипировка оружия (например, посоха или меча)
function equipWeapon(weaponMesh) {
  weaponSocket.clear(); // Удаляем старое оружие
  // Калибровка хвата рукояти
  weaponMesh.position.set(0, 0.05, 0);
  weaponMesh.rotation.set(-Math.PI / 2, 0, 0);
  weaponSocket.add(weaponMesh);
}
2. СМЕНА БРОНИ В РАНТАЙМЕ БЕЗ СБРОСА АНИМАЦИИ (SKINNED MESH SWAP) 
// Замена брони торса на новую модель (например, сет Кармиана)
function swapArmorTorso(newArmorGltf, currentCharacter) {
  // Находим старый меш торса
  const oldTorsMesh = currentCharacter.getObjectByName('tors');
  if (!oldTorsMesh) return;

  // Извлекаем новый меш из загруженного сета
  const newTorsMesh = newArmorGltf.scene.getObjectByName('tors').clone();

  // КРИТИЧЕСКИЙ ШАГ: Привязываем новый меш к СУЩЕСТВУЮЩЕМУ скелету персонажа!
  newTorsMesh.bind(oldTorsMesh.skeleton, oldTorsMesh.bindMatrix);

  // Подменяем в сцене
  const parent = oldTorsMesh.parent;
  parent.remove(oldTorsMesh);
  parent.add(newTorsMesh);

  // Анимация тела (AnimationMixer) продолжает играть без малейшего прерывания!
}
3. СТЕЙТ-МАШИНА ОТДЫХА НА ЗЕМЛЕ (SIT DOWN -> SIT LOOP -> STAND UP) 
// Логика перехода в режим отдыха HP/MP
function sitDown(mixer, actions) {
  const sitDownAction = actions['sit_down'];
  const sitLoopAction = actions['sit_loop'];

  sitDownAction.setLoop(THREE.LoopOnce);
  sitDownAction.clampWhenFinished = true;
  sitDownAction.reset().play();

  // По завершении анимации "садится" переходим в бесконечный "sit_loop"
  mixer.addEventListener('finished', function onSitFinished(e) {
    if (e.action === sitDownAction) {
      mixer.removeEventListener('finished', onSitFinished);
      sitLoopAction.reset().fadeIn(0.2).play();
    }
  });
}

function standUp(mixer, actions) {
  const sitLoopAction = actions['sit_loop'];
  const standUpAction = actions['stand_up'];
  const idleAction = actions['idle'] || actions['walk'];

  sitLoopAction.fadeOut(0.2);
  standUpAction.setLoop(THREE.LoopOnce);
  standUpAction.clampWhenFinished = true;
  standUpAction.reset().fadeIn(0.2).play();

  mixer.addEventListener('finished', function onStandFinished(e) {
    if (e.action === standUpAction) {
      mixer.removeEventListener('finished', onStandFinished);
      if (idleAction) idleAction.reset().fadeIn(0.2).play();
    }
  });
}
