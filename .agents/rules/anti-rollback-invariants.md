# Правило: Защита современной архитектуры и строгий запрет откатов (Anti-Rollback Invariants)

## Контекст и критичность
Проект **Project Steam: Origins** оптимизирован для одновременной поддержки тысяч игроков и ботов при задержке серверного тика < 10 мс. Эта производительность достигается связкой высокотехнологичных нативных C++ компонентов, Worker Threads и Data-Oriented Design.
Откат любого из этих компонентов к устаревшим JavaScript fallback'ам или старым версиям кода приводит к мгновенной деградации сервера (лаги до 2000+ мс, перегрузка CPU 100%, сбои сборщика мусора V8).

## Строгие правила для всех агентов

1. **Запрет на откат сетевого транспорта (uWebSockets.js)**
   - Продакшен-сервер обязан использовать исключительно C++ `uWebSockets.js` (`NET_ENGINE=uws`, `STRICT_UWS=1`).
   - Запрещено переключаться на `ws`.
   - Запрещено советовать или использовать обходные флаги `STRICT_UWS=0`.
   - При сбое `uWebSockets.js` необходимо устранять причину сборки нативного модуля на VPS, а не откатываться на медленный JS.

2. **Запрет на отключение или удаление нативного C++ SIMD модуля**
   - Файлы `native/src/combat_engine.h`, `native/src/spatial_grid.h`, `native/src/main.cpp` и `binding.gyp` являются постоянной частью кодовой базы.
   - Скрипт деплоя обязан передавать директорию `native/` на VPS и собирать модуль через `node-gyp rebuild`.

3. **Запрет на импорт кода из старых зеркал и `scratch/`**
   - Ни при каких обстоятельствах не переносить код из папки `scratch/` или старых бранчей в рабочее дерево.
   - Единственный актуальный источник — текущая директория `project-steam1`.

4. **Запрет на снятие троттлинга ботов**
   - В `server/server.js`:
     - `broadcastMoveVecStart` / `broadcastMoveVecStop`: проверка `if (isOriginBot) return;` обязательна.
     - `clampSpeed`: вызов `GEO.standY` строго ограничен только реальными игроками (`if (!p.yid || !isSyntheticBot(p.yid))`).
     - `ensureNearbyMobs`: проверка `if (p.yid && isSyntheticBot(p.yid)) return;` обязательна.
     - `recomputeAOI`: лимиты ботов (24/32) нельзя объединять с лимитами игроков (128/160).
