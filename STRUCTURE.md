# Project Steam: Origins — Структура проекта

## 📁 Общая архитектура (Client/Server/Shared)

```
project-steam1/
│
├── 📄 package.json               # Node.js зависимости и npm-скрипты
├── 📄 .gitignore
├── 📄 Dockerfile                 # Деплой production-контейнера
├── 📄 render.yaml                # Конфиг деплоя Render.com
├── 📄 README.md                  # Главный обзор проекта и статус
├── 📄 README-SERVER.md           # Инструкция по запуску сервера и переменные окружения
├── 📄 OPTIMIZATION_PLAN.md       # План и статус масштабирования до 5 000 CCU
├── 📄 SERVER_5000_CCU_AUDIT.md   # Аудит узких мест высокой нагрузки
├── 📄 CLIENT_SERVER_AUDIT.md     # Аудит серверного авторитета и античита
├── 📄 SECURITY_AUDIT.md          # Аудит информационной безопасности
├── 📄 PLAN_v2.md                 # Дорожная карта контента 1–20
│
├── 🧩 shared/                    # === ИЗОМОРФНЫЕ МОДУЛИ (Сервер + Клиент) ===
│   ├── net-pack-binary.js        # Zero-Copy бинарный кодек (upd, move)
│   ├── combat-formulas.js        # Формулы урона, критов, физ/маг защиты L2 C1
│   ├── skill-db.js               # Реестр умений, дальности каста, тайминги
│   ├── quest-db.js               # Квесты 1–20: цепочки, диалоги, награды
│   ├── enchant-rules.js          # Правила заточки, шансы, кристаллы при сломе
│   ├── trade-rules.js            # Правила обмена между игроками
│   ├── wh-rules.js               # Правила личного и кланового складов
│   ├── clan-rules.js             # Иерархия кланов, ранги, права, кресты
│   ├── weight-rules.js           # Лимиты веса CON и штрафы движения/боя
│   ├── loot-rules.js             # База предметов, таблицы дропа и спойла
│   ├── game-rules.js             # Базовые константы, статы классов, EXP-таблицы
│   ├── class-system.js           # Дерево классов и требования профессий
│   └── world-metrics.js          # Геометрия мира, регионы, NPC, спавн-споты
│
├── 🖥️ server/                    # === АВТОРИТЕТНЫЙ MMO-СЕРВЕР (Node.js) ===
│   ├── server.js                 # Ядро: WS/HTTP сервер, игровой цикл 10Hz, AOI
│   ├── cluster-manager.js        # Менеджер кластера воркеров (node:cluster)
│   ├── zone-sharding.js          # Межпроцессный шардинг карты по зонам
│   ├── spatial-grid.js           # Пространственная 2D-сетка AOI (ячейки 36м, QuickSelect Top-K)
│   ├── net-transport.js          # Абстракция сетевого сокета (uWebSockets.js / ws)
│   ├── write-behind-cache.js     # Буферизованный асинхронный сброс профилей БД
│   ├── auth.js                   # HMAC-валидация сессий Яндекс SDK
│   ├── db.js                     # Слой данных: JSON-файлы (data/) или PostgreSQL
│   ├── gm-commands.js            # Панель и команды администратора (//)
│   ├── editor-guard.js           # Изоляция инструментов сцены от обычных игроков
│   ├── static-http.js            # HTTP-сервер раздачи клиента и ассетов
│   └── handlers/                 # === ДОМЕННЫЕ ОБРАБОТЧИКИ ПАКЕТОВ ===
│       ├── mob-handler.js        # AI мобов, агро-лист, патрули, смерть
│       ├── party-handler.js      # Группы, приглашения, режимы лута
│       ├── clan-handler.js       # Создание кланов, ранги, кресты
│       ├── trade-handler.js      # Двухфазный защищённый обмен игроками
│       ├── wh-handler.js         # Личный и клановый склады, комиссия
│       ├── duel-handler.js       # Дуэли 1 на 1 до 1 HP без PK
│       ├── private-store-handler.js # Личные лавки (продажа / скупка)
│       ├── chat-handler.js       # Каналы чата (all, shout, tell, party, clan)
│       ├── quest-handler.js      # Диалоги с NPC, прогресс и сдача квестов
│       └── friend-handler.js     # Списки друзей и статусы онлайна
│
├── 📂 data/                      # Персистентные профили игроков (JSON)
│
├── 🌐 client/                    # === КЛИЕНТ (Three.js r185, WebGL) ===
│   ├── index.html                # Главная страница и разметка HUD
│   ├── css/
│   │   ├── style.css             # Базовые стили и адаптивность
│   │   └── l2-hud.css            # Аутентичный интерфейс в стиле Lineage 2
│   └── js/                       # Модули клиента (загружаются через boot.module.js)
│       ├── boot.module.js        # Загрузчик модулей и прелоадер
│       ├── config.js             # Сетевая конфигурация
│       ├── net-ws.js             # WebSocket клиент и парсер бинарных дельт
│       ├── render-setup.js       # Рендерер Three.js, освещение, тени, Sky
│       ├── camera3d.js           # Сферическая камера от третьего лица
│       ├── terrain.js            # Высота ландшафта, вода, Spatial Hash
│       ├── player.js             # Модель игрока, локальная интерполяция
│       ├── char-model.js         # 3D модели персонажей, LOD 0-2, прогрев шейдеров и VRAM
│       ├── combat.js             # Визуализация боя и эффектов
│       ├── ui.js                 # Окна HUD, инвентарь, скиллы, таргет
│       ├── npc-ui.js             # Окна диалогов NPC, магазинов, тренеров
│       ├── i18n.js               # Локализация (RU / EN)
│       └── audio.js              # 3D позиционный звук и фоновая музыка
│
└── 🧪 tests/                     # === НАБОР АВТОТЕСТОВ (3 721 тест) ===
    ├── run.js                    # Тест-раннер с цветным выводом
    ├── server.test.js            # Полный интеграционный WS-тест античита и систем
    ├── db.test.js                # Атомарность дисковых операций и retryFs
    ├── shared.test.js            # Математика формул боя, EXP и правил
    ├── net-pack-binary.test.js   # Тесты бинарного кодека Zero-Copy
    ├── tiered-aoi.test.js        # Тесты многоуровневого квантования AOI
    ├── write-behind-cache.test.js # Тесты отложенного кэша БД
    ├── dead-reckoning.test.js    # Тесты сглаживания перемещения
    └── ... (31 тест-сьют)
```

## 🔄 Архитектура клиент-серверного взаимодействия

```
┌─────────────────────────────────────────────────────────────┐
│                    Браузер (WebGL Client)                   │
│                                                             │
│   • Интерполяция движения (Dead Reckoning)                  │
│   • 3D-рендер Three.js r185 + L2 HUD                        │
│   • Отправка намерений (Intents)                            │
└──────────────────────────────┬──────────────────────────────┘
                               │
           WebSocket (Zero-Copy Binary + JSON Fallback)
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 Node.js Авторитетный Сервер                 │
│                                                             │
│   • Валидация перемещения (Wall-clock Budget + GeoClamp)     │
│   • Spatial Hash Grid (36м ячейки, QuickSelect Top-K)       │
│   • Боевой движок L2 C1 (Hit, Crit, Atk.Spd, BlockCap)      │
│   • Доменные хэндлеры (Квесты, Трейд, Склады, Кланы)        │
│   • Write-Behind кэш (динамический сброс в DB/диск)         │
└─────────────────────────────────────────────────────────────┘
```
